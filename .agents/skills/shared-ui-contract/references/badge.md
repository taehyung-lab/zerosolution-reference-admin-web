# Badge

Read this file only for shared Badge tone, variants, or status rendering.

`Badge` receives a semantic tone and visible content. A feature maps confirmed server status exhaustively to tone and translated label. Do not place server enums, domain/status strings, translation-key construction, or raw-value fallbacks in shared UI.

Read [primitives-and-tokens.md](primitives-and-tokens.md) only when changing token/variant implementation. Test the semantic tone and accessible visible result actually changed.
