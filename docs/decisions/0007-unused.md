# 0007. 결번 (사용되지 않음)

- 상태: 결번 보존
- 날짜: 2026-09-01

이 번호에는 결정이 없다. 재사용하지 않는다.

## 재조사 증거 (2026-09-01)

- `git log --all -- 'docs/decisions/0007*'` 이력 0건. 커밋된 적이 없다.
- `docs`, `AGENTS.md`, `README.md`, `.agents`, `src`, `scripts` 전체에서 문자열 `0007` 참조 0건.

즉 이 번호는 미커밋 상태에서 사라졌거나 애초에 건너뛴 값이며, 복원할 결정 내용이 존재하지 않는다.

## 재번호하지 않는 이유

0008·0009를 앞당기면 `AGENTS.md`, `.agents/skills`, `.ai-work/plans`, ADR 상호 참조가 함께 깨진다.
0009 참조만 27건이며 외부 링크는 저장소가 통제하지 못한다. 결번 하나를 없애려고 실재하는 참조
전부를 이동시키는 것은 비용이 이득을 넘는다.

## 새 결정을 여기에 넣지 않는 이유

ADR 번호는 결정 시점의 순서를 기록한다. 이후에 내려진 결정을 과거의 빈 번호에 채우면 이력이
왜곡된다. 새 결정은 언제나 다음 번호를 받는다.
