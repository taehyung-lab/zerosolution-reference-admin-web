이 화면군의 코드 소유와 구조 판정은 [판정 문서](../zero-sol-figma-analysis.md#구조-판정--회원-2026-09-06)가 소유한다. 이 원장은 관찰과 코드 진입점만 담으며, 구현·검증 상태는 [회원 시나리오](../scenarios/member-list-and-detail.md)가 소유한다.

## Notion 요점 (원문: [notion/04-members.md](notion/04-members.md))

- 검색 gate: "화면 진입시, 검색 안내 화면이 제공된다" — 회원접속·탈퇴회원 명시. 전체·일반·불량·휴면은 "검색 영역과 등록 버튼, 검색 안내 문구가 제공된다"로 같은 의미(Figma 검색전 frame과 일치). 회원상담·소명신청은 문장 없음(Figma도 검색전 없음).
- 초기화: "검색 조건을 default로 설정값을 변경 및 **검색 전 상태로 변경**" (전 화면 동일).
- 보기: "default : 100 or **마지막으로 설정한 값**". 정렬: "default : 가입일(회원)/접수일(상담)/접속일(회원접속) or 마지막으로 설정한 값".
- 목록 검색어: "다중 키워드 검색 허용". "중복 키워드 검색 허용 안함"은 회원 상세 활동정보에만 있으며 목록에는 적용하지 않는다.
- 행 클릭: 전체·일반·불량·휴면·탈퇴 "회원 조회 화면으로 이동". 회원접속 "이벤트 없음".
- bulk 변경: Case01 미선택 → 오류 alert "변경할 항목을 선택해주세요." / Case02 1개 이상 → 확인 alert "선택 항목을 변경하시겠습니까?" → 완료 alert "변경되었습니다." → 화면 갱신.
- SMS·이메일: 미선택 오류 → 1개 이상 선택 시 발송 팝업. 단, [설정 > 정책 > 마케팅] 사용 여부에 따라 정책 설정 alert(Case01·02) 또는 팝업(Case03).
- 다운로드(회원접속·회원상담): `선택`/`전체` 택1, default 미선택. 선택+미선택 → 오류 alert "다운로드할 항목을 선택해주세요.", 전체 → 검색결과 전체 다운로드.
- 상세(회원 공통): 리스트 "페이지 당 100건씩 노출되며, 100건 초과시 페이징 제공". 접수일·답변일 "오늘 이후 선택 불가", 담당자 "로그인 계정 이름 자동 표기".
