## Notion 요점 (원문: [notion/06-ticketing.md](notion/06-ticketing.md))

- 검색 gate 명시: 발권대기·신규발권·분실·일반발권·대량재발권 "화면 진입시, 검색 안내 화면이 제공된다"(14회).
- "DTsol에서 본인이 담당자로 지정된 공연 리스트만 조회할 수 있다" — 발권 전 화면 + 현장발권 (**권한 기반 데이터 범위**).
- 보기 default: 목록 100, **등록 화면(일반발권·대량재발권)은 200** or 마지막 값. 정렬 default 등록일 / 발권완료는 발권일 / 등록·현장은 예매번호.
- 행 클릭 → 발권 조회 화면으로 이동. 일괄변경 3단계 alert 동일. 다운로드 선택/전체 택1 동일(발권대기·신규·재발권·분실·전체발권).
- 발권 실행: "발권PC Client가 실행되지 않은 경우 프로그램 실행 alert", [티켓 발권] 팝업, 발권 취소 확인·재시작 확인 alert.
- 예매채널 "전체, WEB, MOBILE, 현장, CS, 기획사, 기타(공란포함) 중 택1".
