# 전시 배너 조회

## 구성

| 영역 | 관찰 |
| --- | --- |
| 헤더 | 제목 `배너 조회`, breadcrumb `전시 > 배너 > 조회`. ⓘ 없음 |
| 기본정보 (접기 ⌃) | `구분` 홈 · `게시순서` 1 · `배너명` 광고형 배너 · `이동경로` 소제목 아래 `유형` APP 내부 \| `URL` //app/bbs/notice/123 · `이미지` `image.png`(밑줄 링크) · `게시기간` `2026-06-01 12:00:00 ~ 2026-12-31 12:00:00` \| `게시 상태` 게시중 + 흰 버튼 `즉시중단` |
| 업데이트 이력 (접기 ⌃) | 3열 `업데이트일` · `업데이트 사항` · `담당자`. 첫 행 `2026-06-01 13:54:41` / `수정` 아래 `- 게시순서 : 10 > 1`, `- 배너명 : 배너 > 광고형 배너`, `- 이동경로 URL : //app/bbs/motice12 > //app/bbs/motice123`, `- 이미지 : image123.png > image.png` / `김제로(admin)`. 둘째 행 `2026-06-01 12:12:11` / `등록` / `김제로(admin)` |
| 하단 | 검정 `수정`, 밑줄 텍스트 `삭제` |

## 표시 형식

- 일시는 초까지(`2026-06-01 13:54:41`). 게시기간은 한 줄 `시작 ~ 종료`.
- 변경 줄: `- {항목} : {이전} > {이후}`. frame 이 그린 항목은 게시순서·배너명·이동경로 URL·이미지 넷이다.
- 빈 값 `-`(화면 간 원문, 추론).

## 동작

| 동작 | 관찰 | 출처 |
| --- | --- | --- |
| 이미지 | `클릭시, 브라우저 기본 프로세스에 따라 로컬 다운로드 진행됨` | Notion |
| 수정 | `수정 버튼 → 클릭시, 수정 화면으로 이동` | Notion |
| 삭제 | `삭제 버튼 → 클릭시, 삭제 확인 alert 제공 → 삭제하시겠습니까? / 확인, 취소` | Notion |
| 삭제 확인 후 | `확인 : 삭제되며, 삭제 완료 alert 제공` · `확인 : alert 닫히고, 리스트 화면으로 이동` | Notion 화면 간(추론) |
| 이력 | `업데이트 내역 → 업데이트일 : 수정되어 저장된 날짜` | Notion |

## 미확인

| # | 무엇 | 답에 따라 달라지는 것 | 누구에게 |
| --- | --- | --- | --- |
| 1 | `즉시중단` 버튼의 동작 — 바뀌는 상태(종료? 중단?), 확인 문구, 게시중이 아닐 때의 노출 | 조회의 상태 전환 action | 제품 소유자 |
| 2 | 삭제 완료 alert 의 문구(화면 간 원문은 `[삭제 완료 alert]` 존재만 적는다) | 삭제 뒤 alert | 제품 소유자 |
| 3 | 이력 변경 줄의 전체 항목 집합(구분·이동경로 유형·게시기간·게시 상태 변경도 줄이 생기는지) | 이력 mapper 어휘 | 제품·서버 |
| 4 | 이미지 다운로드 URL·파일명 규칙 | 링크 href | 서버 |

## 보류

- `즉시중단`(미확인 1): 버튼을 만들지 않았다. 게시 상태 값만 표시한다.
- 삭제 완료 alert(미확인 2): 문구가 없어 확인 → 요청 성공 뒤 바로 목록으로 간다.
