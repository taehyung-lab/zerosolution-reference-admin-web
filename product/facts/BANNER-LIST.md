# 전시 배너 목록

LNB `전시 > 배너`. 진입 즉시 조회하는 목록이다.

list frame 은 검색 패널 제목 오른쪽에 `+`(펼치기)를 그리고 기간·검색어 두 행만 보인다. Case 정의는 `−` 와 다섯
행을 그린다. 접힘 상태 mechanic 은 공용 `FilterPanel` 이 소유한다.

## 표시 형식

- 게시기간: `2025-12-01 12:00:00 ~` / `2026-12-01 12:00:00` 두 줄, 초까지.
- 등록일/최근업데이트일: `2026-06-01 12:00:00 /` / `2026-06-01 12:00:00` 두 줄, 초까지.
- 게시순서는 정수(`1`), 구분 `홈`, 이동경로 유형 `APP 내부`·`외부 경로`, 게시 상태 `게시중`·`대기`·`종료`.
- 빈 값: 화면 간 원문 `미입력된 정보는 하이픈(-)으로 표기`(추론 — 이 화면 절 밖 문장). 예시 행에 빈 값은 없다.
- 개인정보 표시 없음.

## 연결

- 나가는 전이: 행 → [BANNER-DETAIL](BANNER-DETAIL.md), 등록 → [BANNER-FORM](BANNER-FORM.md). 둘 다 같은 feature 에서 구현.
- LNB `전시` 하위는 frame 이 `배너`·`APP Splash` 를 그린다. `APP Splash`(7.2)는 다른 resource 라 범위 밖이다.
- 공통 문구는 [LIST-COMMON-COPY](LIST-COMMON-COPY.md).

## 보류

- 미리보기 빈 상태 문구(미확인 5): 문구 없이 빈 목록을 그린다.
- `마지막으로 설정한 값` 보관(미확인 4): 만들지 않았다.
