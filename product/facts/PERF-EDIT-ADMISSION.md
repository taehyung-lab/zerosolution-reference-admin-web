# 공연 수정 — 입장안내정보

## 관찰

**편집 대상은 `입장안내정보` 섹션 하나다.** 나머지 섹션(기본정보 · 공연일 회차 · 이벤트 · 공연장 ·
좌석수 · 등급)은 읽기다.

편집 섹션의 구성:

| 항목 | 관찰된 것 |
| --- | --- |
| 안내 도면 | `파일선택` 버튼 + 지원확장자 hint + 선택된 파일 chip(ⓧ). **필수 1개, 최종 선택 파일로 교체** |
| 입력 방식 | select — `구역` / `등급` 중 하나 |
| 반복 행 | 게이트(필수 select) + 입력 방식에 따라 구역(필수 input) 또는 등급(다중 선택). 행별 `삭제`, 섹션에 `추가` |
| 게이트 | **공연장 소속** 중 택1. 최소 1행 |
| 구역 | 필수 · **20자 이하** · 문자 제한 없음 |
| 등급 | **공연 소속** 중 다중 선택 |
| 섹션 액션 | 섹션 안에 `저장` · `취소` |

읽기 섹션의 순서: 구분/공연유형 → **언어 tab(한국어·일본어·영어)** 안의 공연명·부제·출연자·기획/주관
→ 회차별 공연일 → 이벤트명/입퇴장일시 → 공연장 → 좌석수 및 회차별 판매·미판매 → 등급.

## 정책

- 검증 후 **저장 확인** → 저장, 그리고 **취소** 흐름이 있다(Notion).
- 조회 화면의 `수정` 버튼은 **"클릭 시 수정 화면으로 이동"** 이다(Notion). 한편 Figma 관찰은
  `섹션 단위 편집`으로 기록돼 있다. **두 관찰이 같은 지점을 다르게 말한다** — 어느 쪽이 제품의
  확정인지는 아직 답이 없다. 이 선택이 결과를 바꾸면 [미확인](#미확인) 1번으로 다룬다.
- 저장 입력은 **이 섹션이 자기 필드만** 싣는다. 읽기 섹션의 값은 저장 입력에 섞이지 않는다.
- 반복 행의 값과 오류는 **행을 따라간다.** 배열 index 를 행 정체성으로 쓰면 삭제 뒤 오류가 다른
  행으로 옮겨간다.
- 언어 tab 은 읽기 섹션의 표시 상태다. tab 전환이 편집 중인 입력을 잃게 하지 않는다.

## 상태와 소유자

| 값 | 소유자 |
| --- | --- |
| 상세 레코드(읽기 섹션의 모든 값) | Query |
| 입장안내 반복 행 · 파일 · dirty · 검증 | 이 섹션의 폼 |
| 언어 tab 선택 | 가장 가까운 화면 component |
| 어떤 레코드를 여는가 | route params |

## 전이

```text
조회(입력전: 「등록된 정보가 없습니다.」 + 수정) → 수정 진입 → 빈 폼
조회(입력후: 도면 · 입력방식 · 게이트/구역 · 업데이트 이력) → 수정 진입 → 값이 채워진 폼
편집 → 검증 실패면 그 자리에서 거절 → 저장 확인 → 저장 → 조회로 이동
편집 → 취소 → (입력이 있으면 확인) → 조회로 이동
```

입력전 예시에는 이력 행이 없어 이력 절을 렌더하지 않는다.

## 미확인

| # | 무엇이 미확인인가 | 답에 따라 무엇이 달라지나 | 누구에게 묻나 |
| --- | --- | --- | --- |
| 1 | 독립 수정 화면인가, 조회 안 섹션 편집인가 | route 존재 여부와 취소·저장의 목적지 | 제품 — Figma frame 과 Notion 문장이 갈린다 |
| 2 | 업로드 지원 확장자와 용량 상한 | 파일 입력의 accept 와 안내 문구 | 제품 — Figma 에 hint 가 있다는 관찰만 있고 값이 미판독 |
| 3 | 입력 방식(구역↔등급) 전환 시 반대 값의 보존 여부 | 전환 후 재전환의 입력 상태 | 제품 |
| 4 | 섹션별 저장의 mutation 범위와 실제 endpoint | 요청 payload 와 성공 후 무효화 | 서버 계약 |
| 5 | 게이트·등급의 서버 식별자 계약 | 폼 값이 표시 문자열인지 ID 인지 | 서버 계약 |
| 6 | 반복 행의 최대 개수 | 추가 버튼의 상한 | 제품 |
| 7 | 빈 이력 절의 표시 정책 | 이력이 없을 때 절을 그리는가 | 제품 |

미확인은 **그 부분만 보류**한다. 확인된 나머지는 진행한다. 값을 지어내지 않는다.

## 현재 코드

조회 화면과 상세 query 는 구현돼 있고 편집 route·폼·저장은 미구현이다(2026-09-08 기준).
상세 응답은 임시 공급이며 실제 DTO·ID 계약은 [미확인](#미확인) 4·5 다.
