# 게시물 조회

## 관찰

breadcrumb `커뮤니티 > 게시물 > 조회`, 제목 `게시물 조회`. 헤더 오른쪽에 `APP용 URL 복사` 버튼.
섹션 셋은 각각 접기 chevron 을 가진다.

### 기본정보 (읽기 전용)

구분 / 게시판 · 카테고리 · 회원유형 / 회원등급 · 작성자(+`회원 조회` 버튼) / 답변받을 이메일 ·
제목 · 내용(+썸네일 행) · 등록일 / 조회수 · 게시상태.

표시 형식은 목록과 같다 — 빈 값 `-`, 작성자 `이름(마스킹된 이메일)`, 일시 `2026-06-01 12:00:00`.
`답변받을 이메일` 도 마스킹된 값(`your****@email.com`)으로 그려진다.
`게시상태` 행은 **현재 값 옆에 반대 상태 버튼 하나**다(`게시` 옆 `게시안함`).

### 피드백 정보

`좋아요` 10 + `참여자 조회` / `싫어요` 0 + `참여자 조회`(**비활성**) / `평점` 5.0 + `참여자 조회`.
그 아래 한 줄: `댓글 (2)` · 답변상태 select(`대기`) · `답변상태 변경` … 검색 입력 · `선택 ▾` · `변경` ·
`댓글등록`.

댓글 표는 행 checkbox + 카테고리 · 제목 · 내용(+썸네일) · 회원유형/회원등급 · 작성자 · 조회수 ·
게시상태 · `등록일/최근업데이트일`. 목록 표와 컬럼이 다르다.

### 업데이트 이력

3열 `업데이트일 / 업데이트 사항 / 담당자`. 사항은 `등록` · `수정` · `댓글 등록` · `댓글 수정` 네 종류이고
수정 계열에는 `게시상태 : 게시 > 게시안함` 줄이 붙는다. 일시는 초까지(`2026-06-01 13:54:41`).

### 하단

`수정`(primary) · `삭제`.

### 동작 (Notion)

- `수정 버튼 → 클릭시, 수정 화면으로 이동`.
- `삭제 버튼` — 공통 삭제 확인(`1.1.3.1.1`)을 지난다.
- `작성자 → 회원 조회 버튼 → 클릭시, [회원 > 전체회원 > 회원 조회] 중 해당 회원 페이지를 새탭으로 제공`.
- `댓글 → 답변상태 변경 → 대기, 검토중, 완료 중 택1`, `default : 대기`.
- `기본정보 → 내용 → 썸네일 클릭시, 보기 팝업 제공`.
- `좋아요, 싫어요, 평점 → 참여자 조회 버튼 → 클릭시, 참여자 조회 팝업 활성화 → TAB : 좋아요, 싫어요, 평점`.

## 미확인

| # | 무엇이 미확인인가 | 답에 따라 달라지는 것 | 누구에게 |
| --- | --- | --- | --- |
| 1 | `APP용 URL 복사` 가 **어떤 URL 을 복사하는지** | 버튼의 존재와 복사 값 | 제품 소유자 |
| 2 | 댓글 일괄 게시상태 변경의 **확인·완료 문구**. 원문의 3단계 alert 문장은 목록(「게시물 리스트를…」) 절에만 있다. 구현은 같은 공용 문구를 쓴다(**추론**) | 이 표면의 alert 문장 | 제품 소유자 |
| 3 | 댓글 표에 **정렬·페이지가 있는지**. frame 은 마지막 헤더에 정렬 표시를 그리지만 고를 정렬 목록이 없다 | 댓글이 내장 collection 인지 독립 목록 계약인지 | 디자인 원문 소유자 |
| 4 | 댓글 줄의 **검색 입력이 무엇을 좁히는지** | 입력의 존재와 대상 | 제품 소유자 |
| 5 | `싫어요`의 `참여자 조회` 가 비활성인 조건(값 0 인지 게시판 설정인지) | 버튼 활성 규칙 | 제품 소유자 |
| 6 | 운영자 작성자에게도 `회원 조회` 목적지가 있는지. frame 의 예시 행은 APP 회원 하나다 | 버튼을 그리는 조건 | 제품 소유자 |
| 7 | `게시상태` 버튼을 눌렀을 때 확인·완료 alert 이 있는지. 원문이 적지 않는다 | 전이 문장의 유무 | 제품 소유자 |
| 8 | 섹션 chevron 이 실제로 접히는지(렌더로 확인하지 못함) | 섹션의 접기 동작 | 디자인 원문 소유자 |

## 연결

| 목적지 | 상태 |
| --- | --- |
| 게시물 수정(`수정`) | 구현됨 — [POST-FORM](POST-FORM.md) |
| 게시물 목록(삭제 성공 후) | 구현됨 — [POST-LIST](POST-LIST.md) |
| 회원 조회(새 탭) | 구현됨 — 회원 상세 route |
| `참여자 조회` 팝업(9.2.5.2.1~3 좋아요·싫어요·평점) | **범위 내 보류** — 팝업의 목록 계약(정렬 축 참여일·회원유형·회원등급·아이디·이름)만 원장에 있고 열·표시 형식·페이지 규칙을 이 작업에서 열지 못했다. 그 frame 을 판독하면 풀린다. 그때까지 버튼을 그리지 않는다 |
| `댓글등록` 팝업(9.2.5.3) | **범위 내 보류** — 입력·검증·저장이 원문에 없다 |
| `보기` 팝업(9.2.5.1, 썸네일 클릭) | **범위 내 보류** — 팝업이 무엇을 보여 주는지가 원문에 없다 |
| `APP용 URL 복사` | **범위 내 보류** — 미확인 1 |
