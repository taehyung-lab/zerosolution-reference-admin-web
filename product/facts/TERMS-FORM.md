# 약관 등록·수정

## 관찰

등록 제목·브레드크럼은 `{약관1} 등록` · `설정 > {약관1} > 등록`, 수정은 `{약관1} 수정` ·
`설정 > {약관1} > 조회 > 수정` 이다. **두 frame 의 항목 골격이 같고** 수정만 값이 채워져 있다.

### 기본정보 (접이식 섹션)

| 필드 | 관찰된 것 |
| --- | --- |
| 버전 * | 텍스트 입력. 등록 frame 은 입력 안에 `V` 만, 수정 frame 은 `V 1.0` 을 그린다. Notion: `필수선택, 직접선택` · `입력가능문자 : 숫자, 점(.)` · `입력가능글자수 : 10자 이하` |
| 시행일 * | 날짜 입력 + 달력. Notion `default : 미선택`. 수정 frame 값은 `2026-07-01 00:00:00` |
| 게시 상태 * | select. Notion `게시, 게시안함 중 택1` · `default : 게시` |
| 게시일 * | 날짜 입력 + 달력. 수정 frame 값은 `2026-06-01 00:00:00`. 등록 frame 은 빈 입력이고 default 문장이 없다([미확인](#미확인) 4) |
| 본문 * | 큰 편집 영역. 상단에 `html editer` 라는 표기만 있다 |

### 하단

`저장`(primary) · `취소`.

## 정책

- `저장 버튼 → 클릭시, 유효성 체크`.
- `취소 버튼 → 클릭시, 취소 alert 제공`.

## 상태와 소유자

| 값 | 소유자 |
| --- | --- |
| 입력 초안·검증·저장 lifecycle | 이 화면의 폼 |
| 수정의 초기 값 | 조회 Query (`TERMS-DETAIL` 와 같은 선언) |

## 미확인

| # | 무엇이 미확인인가 | 답에 따라 무엇이 달라지나 | 누구에게 묻나 |
| --- | --- | --- | --- |
| 1 | **버전 입력의 `V` 접두 표기.** 저장되는 값은 숫자·점뿐인데 입력 안에 `V` 가 그려진다 | 접두가 장식인가 입력 값의 일부인가 | 디자인 원문 소유자 |
| 2 | **시행일·게시일의 시·분·초.** 수정 frame 의 값에는 시각이 있지만 입력이 시각까지 받는지는 그려져 있지 않다 | 두 입력의 정밀도 | 제품 |
| 3 | **본문 편집기의 허용 요소.** frame 은 `html editer` 라는 표기만 둔다 | 어떤 서식을 넣을 수 있는가 | 제품 |
| 4 | **게시일의 default.** 등록 frame 은 빈 입력이고 원문에 문장이 없다 | 등록 화면의 첫 상태 | 제품 |
| 5 | 저장 성공 뒤의 이동 목적지 | 저장 후 화면 | 제품 |
| 6 | 등록·수정의 서버 계약 | 요청 입력과 성공 후 무효화 | 서버 계약 |

## 보류

- 버전 입력의 `V` 접두 표기는 미확인 1 때문에 그리지 않는다. 값은 숫자·점만 받는다.
- 시행일·게시일의 시·분·초는 미확인 2 때문에 보류하고 날짜까지만 받는다.
- 본문의 HTML 편집기는 미확인 3 때문에 보류하고 여러 줄 텍스트 입력으로 둔다.
